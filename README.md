# deckpipe

Markdown in, branded deck/doc/PDF out. One command. No GUI.

Manual formatting is dead time. This automates it.

---

## Setup

**Dependencies:** `pandoc`, `xelatex` (from `texlive-xetex`), `make`.

```bash
# Check and get install instructions for your OS
./scripts/setup.sh

# Ubuntu / WSL
sudo apt install pandoc texlive-xetex texlive-fonts-recommended make

# macOS
brew install pandoc && brew install --cask mactex

# Extract pandoc reference templates (once, after cloning)
make init-templates
```

---

## Usage

```bash
make deck      # Markdown → output/deck.pptx  (PowerPoint, 16:9)
make pdf       # Markdown → output/deck.pdf   (Beamer PDF slides)
make report    # Markdown → output/report.docx (Word document)
make rpdf      # Markdown → output/report.pdf  (PDF via LaTeX)
make all       # Build all four outputs
make check     # Verify dependencies without building
make clean     # Delete output/
```

Override source files per-project without editing the Makefile:

```bash
DECK_SRC=my-pitch.md make deck
REPORT_SRC=q1-review.md make report rpdf
```

Run `make deck` now to see it work.

## Customisation

**Swap templates:** Replace `templates/deck-template.pptx` or
`templates/report-template.docx` with your own branded reference docs.
Pandoc maps heading styles and slide layouts from your reference doc —
open it in PowerPoint/Word, edit the slide master or paragraph styles,
save, and rebuild.

**Change colours:** Edit `templates/beamer-theme/beamercolorthemedeckpipe.sty`.
The three hex values at the top control the full palette. Rebuild with
`make pdf`.

**Add your logo:** Drop `assets/logo.png` into the `assets/` directory.
Reference it in markdown with `![](assets/logo.png)`. For LaTeX/Beamer,
PNG is most reliable.

**Use your own content:** Point any make target at your markdown file:

```bash
DECK_SRC=path/to/my-deck.md make deck pdf
```

## Directory layout

```
deckpipe/
├── Makefile                        # Build system
├── content/
│   ├── example-deck.md             # 10-slide credit card strategy deck
│   └── example-report.md           # 5-page analytical report
├── templates/
│   ├── deck-template.pptx          # PPTX reference (generated by make init-templates)
│   ├── report-template.docx        # DOCX reference (generated by make init-templates)
│   ├── beamer-theme/               # Custom Beamer theme (LaTeX)
│   └── latex-preamble.tex          # Shared LaTeX preamble
├── assets/
│   └── logo.png                    # Your logo here
├── filters/
│   └── columns.lua                 # Two-column slide support
└── scripts/
    └── setup.sh                    # Dependency check
```
