Plan: Create Beamer-Style Slides via Python (No LaTeX/Beamer Install)
======================================================================

CONTEXT
-------
Recreate the same 4-slide PDF presentation about the India-Canada Summit
(PM Modi & Mark Carney talks, March 2, 2026) entirely through Python,
without installing LaTeX or Beamer.

System findings:
- Python 3.11.14 available
- LibreOffice 24.2.7 already installed at /usr/bin/libreoffice
- None of reportlab, fpdf2, python-pptx, weasyprint, pillow are pre-installed
- Existing files: slides.tex, slides.pdf, build.sh, .gitignore (from previous LaTeX approach)


APPROACH: python-pptx -> LibreOffice PDF
-----------------------------------------
Why this approach:
- python-pptx is a pure pip-installable library; creates real PowerPoint-format
  .pptx slides with proper layouts, themes, and formatting -- the closest Python
  equivalent to Beamer slides.
- LibreOffice is already installed (no new system packages needed) and can
  headlessly convert .pptx -> .pdf reliably.
- No LaTeX/Beamer involved at all; the entire pipeline is:
    pip install python-pptx -> Python script -> LibreOffice conversion

IMPLEMENTATION STEPS
--------------------

Step 1: Create new branch
    git checkout -b claude/python-slides-wP8kb

Step 2: Install python-pptx
    pip install python-pptx

Step 3: Write create_slides.py
    Python script that:
    - Creates a Presentation() with widescreen layout (13.33" x 7.5")
    - Uses a dark/professional color scheme similar to Beamer's Madrid theme
      (dark blue header, white background)
    - Slide 1: Title layout -- big title, subtitle, date/location as footer text
    - Slides 2-4: Content layout -- slide title + bullet points via text_frame
      with nested add_paragraph() for sub-bullets
    - Saves as slides_python.pptx

    Key python-pptx API used:
    - prs = Presentation()
    - prs.slide_width / slide_height for dimensions
    - slide = prs.slides.add_slide(layout) with blank layout (index 6)
    - slide.shapes.add_textbox(left, top, width, height) for text areas
    - tf.text_frame.paragraphs[0].font for styling
    - prs.save('slides_python.pptx')

Step 4: Write build_python.sh
    #!/bin/bash
    pip install python-pptx
    python3 create_slides.py
    libreoffice --headless --convert-to pdf slides_python.pptx
    echo "Done: slides_python.pdf"

Step 5: Run build_python.sh to produce slides_python.pdf

Step 6: Commit and push to claude/python-slides-wP8kb
    Files to commit:
    - create_slides.py
    - build_python.sh
    - slides_python.pptx
    - slides_python.pdf
    Update .gitignore to exclude __pycache__/
